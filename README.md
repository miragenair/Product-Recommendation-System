# Product-Recommendation-System
ML-based e-commerce product recommendation system using Scikit-learn. Backend in Jupyter Notebook implements multiple algorithms (TF-IDF, cosine similarity) with analysis and visualizations. Flask frontend enables real-time recommendations, supported by a MySQL database (XAMPP)

-------------------------------------------------------------------------------------------------------------------------------

**🛍️ ML-Based Product Recommendation System (E-commerce Application)**

This project is a comprehensive **machine learning-driven product recommendation system** integrated into an e-commerce web application. It not only delivers real-time recommendations but also includes an extensive experimental backend exploring multiple recommendation techniques.

The core recommendation engine is developed in **Jupyter Notebook**, where various **Scikit-learn-based algorithms** are implemented, tested, and compared. The system goes beyond basic recommendations by incorporating multiple approaches such as **TF-IDF vectorization, cosine similarity, and other content-based filtering techniques**, along with detailed **data analysis, visualizations, and performance comparisons**.

An entire notebook is dedicated to **exploratory analysis and visualization**, showcasing how different recommendation strategies perform across scenarios using graphs and insights.

The frontend is built with Flask**, enabling users to interact with the system seamlessly, while **MySQL (via XAMPP)** handles structured data storage.

**🔧 Tech Stack:**

* Machine Learning: Scikit-learn, TF-IDF, Cosine Similarity, Multiple Recommendation Algorithms
* Data Analysis & Visualization: Pandas, Matplotlib / Seaborn (in Jupyter Notebook)
* Backend: Jupyter Notebook (ML experimentation + logic)
* Frontend: Flask (HTML/CSS)
* Database: MySQL (XAMPP)

**✨ Features:**

* Multiple recommendation algorithms implemented and compared
* Content-based filtering with TF-IDF and cosine similarity
* In-depth exploratory data analysis and visualizations
* Modular backend with several recommendation functions
* Real-time recommendations through Flask interface
* MySQL database integration for product data management
